# Security Policy

## Reporting a Vulnerability

Kexory takes the security of its projects seriously.

If you discover a potential security vulnerability in a Kexory repository, please report it responsibly.

Do not disclose vulnerabilities publicly through GitHub Issues, Discussions, or other public channels.

## How to Report

Please use GitHub's private vulnerability reporting feature when it is available for the affected repository.

Include the following information whenever possible:

- A clear description of the vulnerability.
- The affected repository, component, and version.
- Steps to reproduce the issue.
- Potential impact.
- Any relevant proof of concept.

## Responsible Disclosure

Please allow the Kexory team reasonable time to investigate and address a reported vulnerability before making it public.

We will review reports, assess their impact, and work toward an appropriate resolution.

## Scope

This policy applies to security vulnerabilities affecting Kexory projects and repositories.

For questions unrelated to security vulnerabilities, use the appropriate public communication channels.
